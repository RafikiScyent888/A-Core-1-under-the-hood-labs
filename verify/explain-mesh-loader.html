What a mesh loader is

Four panels. Nothing here is a diagram — every picture is really rendered, and the loader in panel 3 is a real one, written on this page in 20 lines.

1  Every 3D shape is made of flat triangles

There are no curves in 3D graphics. A cylinder is a fan of flat triangles; enough of them and your eye reads a curve. This is one of the phone's screw bosses — solid on the left, and with the triangles outlined on the right.

3  A mesh loader is the code that reads those numbers out of a file

There are exactly two ways to get the numbers. BUILD them — run a recipe like “cylinder, 0.52 across, 0.30 tall” and let the code work the triangles out. That is what this program does today. Or LOAD them — somebody else worked them out, saved them in a file, and a loader reads the file back in.

To prove it is not a black box: below, the shape from panel 1 has been written out to a file, and then read back by a loader written from scratch on this page. The right-hand picture never touched the recipe. It only ever saw the file.

That is a mesh loader. A real .glb file holds more — colours, picture textures, several objects, a name for each — so a real loader is longer. It is doing the same job.

4  And here is the catch, which is the bit that matters for the labs

The phone's logic board is four separate objects: the green board, the steel shield cans, the black connectors, the gold antenna pads. Four objects means four things a student can be asked to point at, four things that can be named, lit up by a hint, or coloured by whether they have failed.

A mesh made from a photograph arrives as one object with the picture baked onto it. Same shape. Nothing on it to point at.

Built as parts — what is there now

four objects, four names, four colours

The same thing as one fused mesh

one object, one name, one colour

This is the whole trade. A photo-derived mesh can look more like a photograph. It cannot come apart, and it has no separately nameable pieces — so on any bench where the student clicks the model, it stops being an exercise and becomes a picture they can spin.
